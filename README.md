## About This Repository

This repository organizes C programs prepared for Data Structures Lab
practice, revision, and reference. The programs demonstrate common data
structures, algorithms, and their applications.

## Programs Covered

The repository's experiments include topics such as:

1.  Calendar representation using structures and dynamic memory
2.  String or pattern processing
3.  Stack operations and palindrome checking
4.  Infix-to-postfix expression conversion
5.  Postfix expression evaluation
6.  Tower of Hanoi using recursion
7.  Circular queue operations
8.  Singly linked-list operations
9.  Doubly linked-list operations
10. Polynomial operations
11. Binary search tree operations and traversal
12. Graph traversal using depth-first search
13. Hashing with linear probing

## Getting Started

Clone the repository:

``` bash
git clone https://github.com/Suhas810/Data_structures_lab.git
cd Data_structures_lab
```

Compile a C source file with GCC:

``` bash
gcc filename.c -o program
```

Run the compiled program:

``` bash
./program
```

Replace `filename.c` with the source file you want to run. On Windows,
the executable may be run as `program.exe`, depending on your compiler
and terminal.

## Repository Naming Convention

Descriptive filenames make each experiment easier to identify. A
recommended style is:

``` text
<experiment-number>_<topic-name>.c
```

For example:

``` text
01_weekly_calendar.c
04_infix_to_postfix.c
05a_postfix_expression_evaluation.c
05b_tower_of_hanoi.c
```

Keep filenames and experiment labels aligned with the official lab
manual, including separate parts such as **5A** and **5B** where
applicable.
